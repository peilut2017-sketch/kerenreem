### תיקון 37 — תנועות מלאי נכשלו ב״column reference on_hand is ambiguous״

באג שהתגלה בשטח מיד אחרי סבב הבנייה, ומקורו כבר ב-`30_inventory.sql`: הפונקציה `commerce_adjust_stock` מוגדרת עם ‏`returns table (ok, reason, on_hand)` — כלומר `on_hand` הוא **פרמטר פלט** — ובגוף הפונקציה עודכנה העמודה בביטוי לא-מוסמך (`set on_hand = on_hand + p_delta`). ‏plpgsql פותר את הצד הימני בשני מרחבי שמות בו-זמנית (עמודה ופרמטר) ונכשל ב-42702, ולכן **כל** תנועת מלאי ידנית — קליטה, ספירה, נזק, החזרה — נפלה.

התיקון: הסמכה מפורשת (`update inventory_levels il set on_hand = il.on_hand + p_delta`), וכן ב-`select … into v_level` ובשליפת מיקום ברירת המחדל. שם עמודת הפלט נשמר (`on_hand`) כי שכבת הקוד קוראת `row.on_hand`. הקובץ החדש `37_fix_adjust_stock_ambiguity.sql` מחליף את הגרסה מ-30 ומ-36 גם יחד (כולל הסרת ה-overload בן 7 הפרמטרים), ו-36 תוקן בגוף הקובץ כדי שמסד חדש ייבנה תקין מלכתחילה. בנוסף: קוד השגיאה `no_location` קיבל הודעה בעברית במסך המלאי.
