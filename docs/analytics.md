# אנליטיקס עצמאי (v2)

מדידה first-party, בלי עוגיות מעקב, בלי שמירת IP ובלי מזהה קבוע. GA4 נשאר
תוספת אופציונלית שכפופה להסכמת עוגיות. מסך הניהול: `/admin/analytics`.

## מה נאסף ואיפה

| נתון | טבלה | מקור |
|------|------|------|
| צפיה בעמוד (נתיב, שפה, ערוץ, מכשיר, מדינה, בוט) | `page_views` | `AnalyticsBeacon` → `POST /api/analytics/collect` |
| משך שהייה (רק בלשונית גלויה) וגלילה מקסימלית | `page_views.duration_ms / max_scroll` | אותו beacon, בעזיבה/הסתרה → `analytics_record_engagement` |
| מפנה, UTM, עמוד קודם, כניסה לסשן | `page_views` | בכניסה לסשן בלבד (ראו למטה) |
| יציאה לאתר חיצוני, טלפון, דוא"ל, הורדה | `outbound_clicks` | מאזין קליקים גלובלי ב-`AnalyticsBeacon` |
| שמירת ספר | `commerce_events` (`product_saved`) | `useFavourites` (כל כפתורי השמירה) |
| הוספה לסל / מעבר לספק חיצוני | `commerce_events` | `CartProvider`, `ExternalSupplierButton` |

**סשן**: מזהה אקראי ב-`sessionStorage`, תקף 30 דקות חוסר פעילות, נמחק עם
סגירת הלשונית. **מבקר**: גיבוב יומי של IP+UA — לכן "מבקרים" = ימי-מבקר.

## למה הספירה נעצרה על 1000 (ותוקן)

הדשבורד משך את כל השורות בשאילתה אחת עם `.limit(20000)`, אבל PostgREST חותך
תשובות ב-`max-rows` (1000) בשקט. הנתונים נשמרו במלואם; עכשיו כל הצבירה
נעשית ב-Postgres (`analytics_*`, `57_analytics_v2.sql`). אותה תקרה פגעה גם
בדוח הספרים, במונה הצפיות לאירועים ובניקוי הישן (`purgeOldRows`) — תוקנו.

## מקורות לפערים מול GA4

1. GA נטען רק עם הסכמת עוגיות ונחסם ע"י חוסמי פרסומות; כאן נספרים כולם.
2. בוטים וניטור סינתטי: כאן מזוהים לפי User-Agent ומוחרגים (`is_bot`); קודם נספרו.
3. `document.referrer` נשלח קודם בכל ניווט פנימי וניפח את המפנים; עכשיו רק בכניסה לסשן.
4. חלוקה ליום הייתה לפי UTC; עכשיו `Asia/Jerusalem`. ודאו שגם נכס ה-GA כך.
5. "משתמשים" ב-GA = מזהה קבוע; כאן ימי-מבקר. להשוואה — סשנים.
6. גלישת צוות: `אל תספור את הגלישה שלי` במסך האנליטיקס (גם מנטרל GA).

## GA4 — אירועים שנשלחים (רק עם הסכמה)

`view_item`, `add_to_wishlist`, `add_to_cart`, `supplier_click`, `tel_click`,
`mailto_click`. גלילה, לחיצות יוצאות והורדות — מדידה משופרת של GA עצמו.

## הרחבות מומלצות (לא ממומשות)

חיפוש פנימי (מונחי חיפוש ללא תוצאות), משפכי המרה צפייה→סל→תשלום לפי ערוץ
הגעה, הכנסה לפי ערוץ (דורש חיבור `orders` לסשן), השוואת שפות, התראה על ירידה
חדה בצפיות.
